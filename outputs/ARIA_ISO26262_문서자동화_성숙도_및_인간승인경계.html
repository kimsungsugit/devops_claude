01

완료 가정

CORE·UDS·STS·SUTS·SITS·결과 문서·RAG 작업과 회귀시험, 실제 VectorCAST 파일럿을 모두 통과한 운영상태입니다.

02

명세 도착점

UDS·STS·SUTS·SITS는 필수·안전중요 필드가 모두 처리되고 미해결 BLOCK이 없는 A3-S 검토 준비형 명세로 운영됩니다.

03

실행증거 도착점

SUTS·SITS의 도구 TC·실행결과·커버리지·기준선이 정합되고 결과 문서 4종은 A3-E 검토 준비형 증거 패키지로 운영됩니다.

04

사람 승인 경계

요구·설계 의도, ASIL, 판정 기준, 편차와 최종 서명은 A4 사람 승인입니다. 자동화 완료가 ISO 인증이나 전체 V-model 완료를 뜻하지 않습니다.

A4 승인 완료

사람 승인 전용 영역

ARIA가 A3-S/A3-E 산출물을 준비해도 A4는 검토자와 승인자가 책임지는 최종 상태입니다.

자동화 목표는 “사람 없는 승인”이 아니라 “근거가 정리된 효율적인 승인”입니다.

기능 목적, 안전 메커니즘과 상위 요구 연결이 실제 시스템 의도에 맞는지 판단합니다.

ASIL 등급, 조정 적용, 커버리지 목표와 ISO 26262 방법의 프로젝트 적용성을 확정합니다.

03 시험 판정 기준

정상·경계·오류·상태전이의 기대값과 합격 기준이 안전 요구를 검증하는지 승인합니다.

04 동적·하드웨어 동작

함수 포인터, 비동기 흐름, 타이밍, 동시성, 실제 I/O와 하드웨어 상호작용을 확인합니다.

05 편차와 예외

미도달 코드, 방어코드, MC/DC 불가, 커버리지 예외와 실패 수용의 근거를 검토합니다.

06 최종 서명

시험환경 대표성, 결과 적합성, 잔여 리스크와 배포 적용 여부를 확인하고 서명합니다.

본 완료 가정 시나리오에서 공통 계약, 문서별 검증 관문과 회귀시험이 적용되어 UDS·STS·SUTS·SITS는 단순 자동작성 초안이 아니라 A3-S 검토 준비형 명세로 운영된다. 이는 근거·추적성·시험 판정 기준과 미해결 상태가 결속되어 승인 검토에 바로 투입할 수 있다는 뜻이며, ISO 26262 인증이나 사람의 A4 승인을 뜻하지 않는다. SUTS·SITS 실행 연계와 결과 문서 4종은 실제 VectorCAST 반입·컴파일·실행·재수집·TC ID 왕복 정합을 포함한 A3-E 실행증거 패키지로 운영된다. 요구·설계 의도, ASIL, 시험 판정 기준, 동적·하드웨어 동작, 편차와 최종 서명은 사람이 책임진다.
